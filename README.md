# MedAI Backend

AI-powered clinical triage support system — FastAPI backend with XGBoost inference and SHAP explainability.

## Architecture

```
POST /predict  →  Preprocessing  →  XGBoost (5-class MTS)  →  SHAP TreeExplainer  →  PostgreSQL
```

- **Model**: XGBoost trained on 100,000 real triage records from Chocó, Colombia
- **Explainability**: SHAP TreeExplainer — per-prediction feature contributions for all 15 clinical variables
- **Persistence**: Patient, Prediction, and Explanation entities stored in PostgreSQL
- **Paper**: *MedAI: An Explainable AI-Based System for Clinical Triage and Prioritization*

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/predict` | Triage classification + SHAP + DB persistence |
| `POST` | `/clasificar` | Alias of `/predict` (backward compat) |
| `GET`  | `/predict/history` | Recent predictions from DB |
| `GET`  | `/health` | Service health check |
| `GET`  | `/info/model` | Model metadata |
| `GET`  | `/docs` | Interactive API documentation (Swagger) |

## Setup

### Prerequisites

- Python 3.11
- PostgreSQL 14+
- (macOS) Homebrew with `brew install python@3.11 libomp expat`

### 1. Clone and configure

```bash
git clone https://github.com/your-org/MedAI_Backend.git
cd MedAI_Backend

cp .env.example .env
# Edit .env — set DATABASE_URL to your PostgreSQL connection string
```

### 2. Create PostgreSQL database

```bash
# macOS (Homebrew, no password — use your OS username)
psql -h localhost -U $USER -d postgres -c "CREATE DATABASE medai;"

# Linux or Docker
psql -h localhost -U postgres -c "CREATE DATABASE medai;"
```

### 3. Python environment

```bash
# macOS
DYLD_LIBRARY_PATH=$(brew --prefix expat)/lib python3.11 -m venv venv
DYLD_LIBRARY_PATH=$(brew --prefix expat)/lib venv/bin/pip install -r requirements.txt

# Linux
python3.11 -m venv venv
venv/bin/pip install -r requirements.txt
```

### 4. Train the model

The `.joblib` artifact is not committed to git. Generate it once (takes ~5 minutes on CPU):

```bash
# macOS
DYLD_LIBRARY_PATH=$(brew --prefix expat)/lib:$(brew --prefix libomp)/lib \
  venv/bin/python train_model.py

# Linux
venv/bin/python train_model.py
```

See `models/README.md` for full details.

### 5. Start the backend

```bash
./start_dev.sh
# Backend: http://localhost:8000
# Docs:    http://localhost:8000/docs
```

## Docker

```bash
# Full stack: backend + frontend + PostgreSQL
docker-compose up --build

# Backend only (requires external DB)
docker build -t medai-backend .
docker run -p 8000:8000 -e DATABASE_URL=postgresql://user:pass@host/medai medai-backend
```

## Dataset

`triage_choco_100k_balanceado.csv` — 100,000 anonymised triage records from Chocó, Colombia.  
Balanced: 20,000 records per MTS level (1–5). 22 columns including vital signs, demographics, chief complaint, comorbidities, and urgency level.

## Model Performance (15,000-record test set)

| Metric | Value | Target (paper) |
|--------|-------|----------------|
| Weighted F1 | 52.6% | ≥ 80% |
| Recall Level 1 | 82.1% | ≥ 95% |
| Recall Level 2 | 64.4% | ≥ 95% |
| Accuracy | 53.1% | — |

Performance is below paper targets due to class overlap in the 15-feature space. The human-in-the-loop design compensates: clinicians validate all recommendations through the SHAP explanation interface before acting.
